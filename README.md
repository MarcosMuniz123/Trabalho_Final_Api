# Trabalho Completo - Marcos Muniz - API Spring Boot

Este é um projeto de API REST desenvolvido em Java utilizando o framework Spring Boot.

## 💻 Tecnologias e Ferramentas

* **Java**
* **Spring Boot:** Framework principal para a construção da API.
* **Maven:** Gerenciador de dependências do projeto.
* **H2 Database:** Banco de dados em memória, utilizado para o desenvolvimento e testes da aplicação.

## 🛠️ Ferramentas de Desenvolvimento

* **Spring Tools Suite (STS):** A IDE utilizada para o desenvolvimento e gerenciamento do projeto.
* **Postman:** Ferramenta utilizada para criar, testar e validar os endpoints (rotas) da API.

## 🚀 Como Executar

1.  Clone este repositório.
2.  Abra o projeto no Spring Tools Suite (ou outra IDE com suporte ao Maven).
3.  Aguarde o Maven baixar todas as dependências listadas no `pom.xml`.
4.  Execute a classe principal que contém a anotação `@SpringBootApplication`.
5.  A API estará rodando (geralmente em `http://localhost:8080`).
